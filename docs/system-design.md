# 系统设计文档

## 1. 系统概述

### 1.1 项目背景

AntiCheat 是一个面向 Minecraft 服务器的反作弊管理系统，旨在帮助服务器管理员实时监控玩家行为、检测作弊行为、管理封禁记录，并提供完善的举报处理机制。

### 1.2 系统目标

- 实时检测并记录玩家作弊行为
- 提供直观的管理后台界面
- 支持自动/手动封禁管理
- 实现举报处理工作流
- 提供数据统计与分析功能

### 1.3 技术选型

| 层次 | 技术栈 | 版本 |
|------|--------|------|
| 前端框架 | Vue.js | 3.x |
| UI组件库 | Element Plus | 2.x |
| 图表库 | ECharts | 5.x |
| 构建工具 | Vite | 5.x |
| 后端框架 | Spring Boot | 3.2.x |
| 安全框架 | Spring Security | 6.x |
| 认证方案 | JWT | - |
| 数据访问 | Spring Data JPA | 3.x |
| 数据库 | H2 / MySQL | 8.0+ |
| 游戏插件 | Spigot/Paper | 1.20+ |
| 实时通信 | WebSocket | - |

## 6. 性能设计

### 6.1 前端优化

- **路由懒加载**: 按需加载组件，减少首屏加载时间
- **组件缓存**: 使用 keep-alive 缓存频繁切换的组件
- **虚拟滚动**: 大数据列表使用虚拟滚动
- **防抖节流**: 搜索输入使用防抖处理

### 6.2 后端优化

- **数据库连接池**: HikariCP 高性能连接池
- **JPA缓存**: 二级缓存减少数据库访问
- **异步处理**: 定时任务异步执行
- **分页查询**: 大数据量分页加载
