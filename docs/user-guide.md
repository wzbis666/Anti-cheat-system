## 1. 系统简介

### 1.1 系统概述

AntiCheat 是一个专为 Minecraft 服务器设计的反作弊管理系统，提供实时作弊检测、封禁管理、举报处理等功能，帮助服务器管理员维护公平的游戏环境。

### 1.2 主要功能

| 功能模块 | 描述 |
|----------|------|
| 📊 仪表盘 | 数据概览、实时统计、告警通知 |
| 👥 玩家管理 | 玩家列表、风险评分、信息查看 |
| 📋 作弊记录 | 作弊日志、类型统计、详情查看 |
| 🔨 封禁管理 | 永久/临时封禁、解封操作 |
| 📝 白名单 | 白名单管理、信任玩家设置 |
| 📢 举报管理 | 举报处理、违规确认 |
| ⚙️ 系统设置 | 参数配置、系统管理 |

### 1.3 系统角色

| 角色 | 权限 |
|------|------|
| 管理员 (Admin) | 所有功能完全访问权限 |
| 用户 (User) | 查看仪表盘、个人中心 |

## 2. 快速开始

### 2.1 访问系统

1. 打开浏览器，访问系统地址
   - 开发环境: `http://localhost:3000`
   - 生产环境: `https://your-domain.com`

2. 进入登录页面

### 2.2 登录系统

#### 管理员登录

1. 选择「管理员」标签页
2. 输入用户名: `admin`
3. 输入密码: `admin123`
4. 点击「登录」按钮

> ⚠️ **安全提示**: 首次登录后请立即修改默认密码！

#### 用户登录

1. 选择「用户」标签页
2. 输入注册的用户名和密码
3. 点击「登录」按钮

### 2.3 用户注册

1. 在登录页面点击「没有账号？立即注册」
2. 填写注册信息:
   - 用户名 (3-20字符)
   - 密码 (至少6位)
   - 确认密码
   - 昵称 (可选)
   - 邮箱 (可选)
3. 点击「注册」按钮

### 2.4 语言切换

系统支持中英文切换:
1. 在登录页面底部找到语言切换按钮
2. 点击「中文」或「EN」切换语言

## 3. 功能模块

### 3.1 仪表盘 (Dashboard)

仪表盘是系统的首页，展示关键数据和实时告警。

#### 数据卡片

| 卡片 | 说明 |
|------|------|
| 玩家总数 | 当前系统记录的玩家数量 |
| 作弊记录 | 作弊检测记录总数 |
| 封禁中 | 当前生效的封禁数量 |
| 待处理举报 | 等待处理的举报数量 |

#### 图表展示

- **风险等级分布**: 线形图展示不同风险等级的玩家分布
- **作弊类型统计**: 饼图展示各类作弊行为的占比

#### 实时告警

- WebSocket 连接状态指示器
- 作弊行为实时推送通知
- 点击通知可查看详情

### 3.2 玩家管理 (Players)

管理服务器中的玩家信息。

#### 功能列表

| 功能 | 操作 |
|------|------|
| 查看列表 | 显示所有玩家，包含名称、UUID、风险评分、最后在线时间 |
| 搜索玩家 | 按名称搜索特定玩家 |
| 风险筛选 | 按风险等级筛选（低/中/高/极高） |
| 修改评分 | 手动调整玩家风险评分 |
| 查看详情 | 查看玩家详细信息和作弊记录 |
| 删除玩家 | 从系统中移除玩家记录 |

#### 风险等级说明

| 等级 | 分数范围 | 颜色标识 |
|------|----------|----------|
| 低风险 | 0-30 | 🟢 绿色 |
| 中风险 | 31-60 | 🟡 黄色 |
| 高风险 | 61-80 | 🟠 橙色 |
| 极高风险 | 81-100 | 🔴 红色 |

### 3.3 作弊记录 (Cheats)

查看和管理作弊检测记录。

#### 功能列表

| 功能 | 操作 |
|------|------|
| 查看列表 | 显示所有作弊记录 |
| 分页浏览 | 支持分页查看大量数据 |
| 类型筛选 | 按作弊类型筛选记录 |
| 排序 | 按时间、严重程度排序 |
| 查看详情 | 查看作弊详细信息 |
| 删除记录 | 删除指定记录 |

#### 作弊类型

| 类型 | 英文 | 描述 |
|------|------|------|
| 杀戮光环 | KILLAURA | 自动攻击周围玩家 |
| 飞行作弊 | FLY | 非法飞行 |
| 加速作弊 | SPEED | 移动速度异常 |
| 透视作弊 | XRAY | 穿墙透视矿物 |
| 自动点击 | AUTOCLICKER | 自动点击攻击 |
| 攻击距离 | REACH | 攻击距离异常 |
| 其他 | OTHER | 其他作弊行为 |

### 3.4 封禁管理 (Punishments)

管理玩家封禁记录。

#### 封禁类型

| 类型 | 说明 |
|------|------|
| 永久封禁 (PERMANENT) | 永久禁止进入服务器 |
| 临时封禁 (TEMPORARY) | 指定时间后自动解封 |

#### 封禁操作

1. **封禁玩家**
   - 点击「封禁玩家」按钮
   - 输入玩家 UUID 或名称
   - 选择封禁类型
   - 填写封禁原因
   - 如为临时封禁，设置封禁时长
   - 点击确认

2. **解封玩家**
   - 在封禁列表找到目标记录
   - 点击「解封」按钮
   - 确认解封操作

3. **查看封禁记录**
   - 状态筛选：生效中/已过期
   - 查看封禁详情

#### 自动解封

系统定时任务会自动检查临时封禁记录，到期后自动解封。

### 3.5 白名单 (Whitelist)

管理服务器白名单玩家。

#### 功能列表

| 功能 | 操作 |
|------|------|
| 查看列表 | 显示所有白名单玩家 |
| 添加白名单 | 添加玩家到白名单 |
| 移除白名单 | 从白名单移除玩家 |
| 搜索 | 按名称搜索白名单玩家 |

#### 白名单作用

- 白名单玩家不受自动封禁影响
- 白名单玩家的作弊行为仍会被记录
- 适用于信任的管理员和资深玩家

### 3.6 举报管理 (Reports)

处理玩家提交的举报。

#### 举报状态

| 状态 | 说明 |
|------|------|
| 待处理 (PENDING) | 等待管理员处理 |
| 已解决 (RESOLVED) | 确认违规，已处理 |
| 已驳回 (REJECTED) | 不构成违规，已驳回 |

#### 处理举报

1. 在举报列表选择待处理的举报
2. 点击「处理」按钮
3. 选择处理结果:
   - **确认违规**: 举报成立
   - **驳回举报**: 举报不成立
4. 填写处理备注
5. 可选：勾选「封禁该玩家」
6. 点击确认

#### 举报类型

| 类型 | 说明 |
|------|------|
| 作弊 (CHEATING) | 使用作弊软件 |
| 黑客 (HACKING) | 账号被盗或黑客行为 |
| 破坏 (GRIEFING) | 恶意破坏建筑 |
| 骚扰 (HARASSMENT) | 骚扰其他玩家 |
| 其他 (OTHER) | 其他违规行为 |

### 3.7 系统设置 (Settings)

配置系统参数。

#### 可配置项

| 配置项 | 说明 |
|--------|------|
| 自动封禁开关 | 是否启用自动封禁 |
| 自动封禁阈值 | 触发自动封禁的风险评分 |
| 最大风险评分 | 玩家风险评分上限 |

### 3.8 个人中心 (Profile)

管理个人账户信息。

#### 功能

- 查看个人信息
- 修改昵称、邮箱
- 绑定 Minecraft 账号
- 修改密码
- 上传头像

## 4. 操作指南

### 4.1 封禁玩家完整流程

```
1. 进入「玩家管理」页面
2. 搜索或浏览找到目标玩家
3. 点击玩家名称查看详情
4. 确认玩家信息无误
5. 进入「封禁管理」页面
6. 点击「封禁玩家」按钮
7. 填写封禁信息:
   - 玩家 UUID
   - 玩家名称
   - 封禁类型
   - 封禁原因
   - 封禁时长(临时封禁)
8. 点击「确认封禁」
9. 在仪表盘查看封禁状态更新
```

### 4.2 处理举报完整流程

```
1. 进入「举报管理」页面
2. 查看待处理举报数量
3. 选择一条待处理举报
4. 点击「处理」按钮
5. 查看举报详情:
   - 举报人信息
   - 被举报人信息
   - 举报原因
   - 举报时间
6. 选择处理结果
7. 填写处理备注
8. 如需封禁，勾选「封禁该玩家」
9. 点击「确认」
10. 举报状态更新为已处理
```

### 4.3 添加白名单流程

```
1. 进入「白名单」页面
2. 点击「添加白名单」按钮
3. 填写玩家信息:
   - 玩家名称
   - 玩家 UUID
   - 添加原因
4. 点击「确认添加」
5. 白名单列表更新
```

## 5. 常见问题

### Q1: 忘记密码怎么办？

**答**: 请联系系统管理员重置密码。

### Q2: 为什么 WebSocket 显示未连接？

**答**: 可能原因：
1. 后端服务未启动
2. 网络连接问题
3. 防火墙阻止 WebSocket 连接

解决方法：
1. 检查后端服务状态
2. 刷新页面重试
3. 检查浏览器控制台错误信息

### Q3: 登录后立即退出怎么办？

**答**: 可能原因：
1. Token 已过期
2. 后端服务重启

解决方法：
1. 清除浏览器缓存
2. 重新登录

### Q4: 数据没有实时更新怎么办？

**答**: 
1. 检查 WebSocket 连接状态
2. 手动刷新页面
3. 检查后端服务是否正常运行

### Q5: 如何修改默认管理员密码？

**答**: 
1. 登录管理员账户
2. 进入「个人中心」页面
3. 点击「修改密码」
4. 输入旧密码和新密码
5. 点击确认

### Q6: 临时封禁到期后没有自动解封？

**答**: 
1. 检查系统定时任务是否正常运行
2. 手动解封该玩家
3. 查看后端日志排查问题
